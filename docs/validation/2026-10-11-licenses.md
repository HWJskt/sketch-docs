# 병원 내부 웹 배포와 라이선스 검토

확인일: 2026-10-11. 현재 `upstreams.lock.json`에 고정된 원문과 실제 생성물을 검토했다. 법률 자문이나 의료정보 시스템 적합성 인증은 아니다.

## 확인한 라이선스

| 구성 | 현재 판 | 조건과 판단 |
|---|---|---|
| EdenText | 0.9.0 / `4c4c94cb` / AGPL-3.0-only | 병원 업무용·상업적 사용 가능. 수정본 배포 시 AGPL에 따른 고지와 해당 버전의 대응 소스 제공 필요 |
| HOP | 0.4.5 / `80888af2` / MIT | 업무용 웹 배포·수정·상업 이용 가능. 저작권·허가·면책 문구 보존. MIT 자체는 수정 소스 공개나 로그인 의무 없음 |
| rhwp 및 HOP vendor WASM | 0.8.7 / `1a76570e` / MIT | HOP와 동일. WASM 사용도 라이선스 고지 대상 |
| CanvasKit | 설치 패키지 0.42.0 / BSD-3-Clause | 배포 시 고지 보존, 원저작자 보증·후원으로 표시하지 않을 것 |
| 기타 라이브러리·폰트·사전 | MIT/Apache/BSD/MPL/OFL/GUST 등 | 각 자산 조건이 남는다. 최상위 MIT 또는 AGPL만으로 모든 자산의 의무가 사라지지 않는다 |

사용자가 지정한 localhost `engines/word/licenses.txt`를 HTTP로 받아 생성된 파일과 SHA-256이 같은 것을 확인했다. 파일은 EdenText 자체 AGPL과 외부 구성요소를 구분하며, 폰트·사전·동의어 자료 고지는 별도 경로임을 명시한다. HOP/rhwp 전체의 고지 목록이 아니다.

## AGPL과 로그인

브라우저에 전송되는 JS/WASM도 소프트웨어 사본이므로 단순히 서버에서 실행되는 SaaS인지 여부만 검토해서는 안 된다. AGPL §6의 소스 제공 조건과 수정본의 네트워크 사용에 대한 §13을 고려해 실제 사용자가 해당 배포판 소스를 무료로 받을 수 있도록 구성한다. 원본 EdenText 저장소 링크만으로 우리 수정본의 소스를 제공했다고 볼 수 없다.

공개 무로그인 서비스라면 익명 사용자도 대응 소스에 접근할 수 있게 해야 한다. 직원 전용 인증 서비스라면 실제 이용 직원에게 소스 접근을 제공하는 형태가 가능하다. 로그인으로 소스 제공 의무가 면제되지는 않는다. AGPL 소스를 받은 사람의 재배포 권리를 NDA 등으로 제한하는 방식도 피해야 한다. 독립적인 다른 병원 시스템 전체가 자동으로 공개 대상이 된다고 단정하지 않지만, EdenText 파생 변경과 실행·빌드에 필요한 연결 코드·스크립트·고정 원본은 제공 범위에 넣는 방식이 명확하다.

로그인은 어느 라이선스도 요구하지 않는다. 직원 전용 운영은 병원 SSO 또는 VPN/접근 프록시를 권장한다. 이는 접근 통제에 관한 운영 판단이며 이 검토만으로 의료정보 관련 법적 의무를 판정하지 않는다. 로컬 파일 저장과 브라우저 복구 데이터는 서버 로그인만으로 보호되지 않는다. EdenText AI 기능에는 구성한 endpoint로 보내는 네트워크 코드가 있으므로, 환자정보를 다룬다면 외부 전송·공용 PC의 로컬 데이터 정책도 별도로 검토한다.

일반적으로 작성한 병원 문서·환자 데이터는 편집기 소스 공개 대상이 아니다. 프로그램 코드를 문서에 포함하는 등의 별도 사정 없이 편집기로 작성했다는 이유만으로 문서가 AGPL이 되지 않는다.

## 현재 배포 전 남은 작업

1. 우리 수정본·빌드 스크립트·고정 upstream을 재현할 수 있는 대응 소스 다운로드와 눈에 띄는 안내, 수정 사실·날짜 표시를 마련한다. 현재 About의 저장소 링크는 upstream만 가리킨다.
2. HOP/rhwp MIT 원문은 생성물에 복사되지만 rhwp `THIRD_PARTY_LICENSES.md`, CanvasKit 등 의존성의 고지 묶음은 별도로 배포물에 포함해야 한다. Rust 전이 의존성 각각의 최종 WASM 포함 여부와 고지 완전성까지 전수 감사하지 않았다.
3. 배포된 한글 폰트 폴더에는 `FONTS.md`와 SourceHanSerifK OFL 원문이 있다. 나머지 글꼴은 각 폰트 메타데이터의 라이선스·저작권 고지까지 확인하고 필요 문서를 동봉한다. OFL은 조건을 지킨 웹폰트 사용을 허용한다. GUST와 Cafe24/행복고딕은 해당 조건을 따로 유지한다.
4. Cafe24 공식 안내는 웹폰트·소프트웨어 번들 사용을 허용한다. 행복고딕은 upstream 목록의 '무료 배포' 표기만 확인했으며, 권리자 원문을 확보해 이 배포 형태의 조건을 확인하는 작업이 남아 있다. 무료 표기만으로 조건 없는 재배포라고 단정하지 않는다.

따라서 **라이선스 유형상 병원 웹 배포는 가능하나 현재 생성물이 배포 의무를 모두 충족했다고 확정하지 않는다.** 로그인 구현·공개 배포·소스 공개는 이번 검토에서 수행하지 않았다.
