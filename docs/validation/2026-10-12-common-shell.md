# Sketch Docs 공통 셸 구현 검증

2026-10-12. 사용자 지정 제품명 Sketch Docs를 적용했다. 원본 클론을 수정하지 않고 루트 셸과 빌드용 오버레이에 구현했다.

## 구현

- Word·한글 위 40px 공통 헤더, 같은 위치의 선택 버튼과 활성 표시.
- 최초 선택 시 엔진 로드, 전환 후 iframe/컴포넌트를 유지하여 본문·표·파일 연결을 보존. 숨긴 영역은 hidden/inert 처리한다.
- Word 상태 브리지와 한글 상태 조회를 통해 파일 작업 중 전환 차단, 비활성 문서까지 이탈 경고에 포함. 기존 Word 한글 열기 경로도 셸에 연결한다.
- 첫 화면 및 양쪽 헤더의 공통 정보 창. Sketch Docs 0.1.0, AGPL 원문, upstream 정보, 수정 사실, 타사 고지, 실제 소스 다운로드.
- 빌드에 대응하는 제품 소스·lock·원본 Git 객체·복원 도구를 약 153 MB tar.gz로 생성. source/backups/개발자 설정을 무차별 복사하지 않는다. rhwp의 대형 PDF·샘플 자료는 sparse checkout에서 제외하고 빌드 소스와 검사 fixture는 보존한다.
- 기존 EdenText 정보 창과 원저작자 라이선스는 보존한다. 저작권자 명칭은 사용자 지정 전까지 임의 작성하지 않는다.

## 실행 결과

`volta run --node 24.21.0 npm run verify` 통과.

- 제품 및 생성된 Word 타입 검사: 각각 오류 0, 경고 0.
- 파일 쓰기 계약 3개, 소스 패키지 계약 2개 통과.
- Chrome 프로덕션 회귀: DOCX 기본 저장과 본문/표 직렬화, HWP/HWPX 저장·재열기, 외부 파일 변경 감지, 사본 저장 대상 분리, 실패한 열기 후 기존 문서 유지.
- 공통 헤더: Word 본문/표 → 한글 본문/표 → 왕복, history 뒤로/앞으로, 기존 Word 저장 대상 유지, 저장 선택기 대기 중 전환 차단과 취소 복구.
- 정보 창: 첫 화면/편집 화면, Escape 및 포커스 복귀, 소스·고지 링크 HTTP 200, 390px 헤더 범위 확인.
- 한글 엔진 로딩 실패를 주입한 뒤 Word 문서 보존 확인. Word 엔진 오프라인 새로고침 검사 유지.
- 두 엔진 로드 뒤 Chrome JSHeapUsedSize 91,234,384 bytes 관측. WASM/GPU/브라우저 전체 메모리 수치가 아니며 저사양 기기 보장값이 아니다.
- 별도 소스 추출본에서 네트워크 없이 정확한 세 upstream SHA 복원, clean status 및 HOP 계약 검사 통과.
- Svelte autofixer: 오류 없음. 외부 상태 전달 effect와 iframe/컴포넌트 참조의 bind:this 권고는 용도상 유지.

분리된 정적 점검에서 이미지 전용 새 Word 문서의 dirty 누락과 기존 메뉴의 busy 검사 우회를 발견하여 수정했다. 전체 verify는 수정 후 실행했다.

## 남은 검증과 배포 조건

실제 OS 파일 선택기, Word/한컴오피스 앱 재열기, 한국어 IME와 병원 대표 문서는 수동 검증이 필요하다. 390px에서는 공통 헤더가 유지되지만 원본 한글 도구·페이지는 데스크톱용이며 모바일 편집 지원으로 간주하지 않는다. Safari는 검사하지 않았다.

새로고침 후 한글 자동 복구 및 가져온 한글 원본 덮어쓰기는 별도 작업이다. 라이선스·폰트의 추가 고지와 출처 검토는 기존 라이선스 기록에 남아 있다. 소스 다운로드 구현은 전체 법률 검토 완료를 뜻하지 않는다. 라이브 배포·원격 push는 실행하지 않았다.

## 같은 날 메뉴 행 통합 변경

사용자 요청으로 독립된 40px 헤더를 제거했다. Word의 리본 탭 행과 한글의 메뉴 행을 각각 기존 높이로 유지하고 오른쪽에 `W / 한 / ⓘ`를 배치한다. 동일한 공통 버튼 컴포넌트를 각 iframe의 메뉴 행에 mount하고, 엔진이 새로고침되면 다시 연결한다. iframe의 높이를 줄이지 않아 편집 영역에 40px를 돌려준다. 로딩 실패 시에도 루트 오른쪽에 전환 버튼을 남겨 기존 문서로 돌아갈 수 있다.

좁은 화면은 기존 메뉴 영역만 가로 스크롤하고 전환 버튼은 고정한다. 한글 드롭다운이 스크롤 영역에 잘리지 않도록 별도 배치한다. 회귀 검사에 메뉴 항목의 실제 hit-test, iframe 시작 y=0, 두 편집기의 버튼 오른쪽 좌표 일치를 추가했다.
