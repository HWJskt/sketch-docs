# 원본 클론 분리와 통합 셸 검증

기준일: 2026-10-11. 실행·업데이트 명령의 정본은 [README](../../README.md)다.

## 구현 구조

프로젝트 루트가 제품 저장소다. 형식 선택 화면, iframe 연결, 한글 파일 메뉴, 번역·변환 패치, 빌드·검증 코드를 관리한다. `source/edentext`와 `source/hop`는 upstream 원본 클론으로 유지한다. 빌드 시 고정 커밋을 `.cache`로 복사한 뒤 우리 변경을 적용하므로 원본 파일을 고치지 않는다.

한글 엔진은 HOP가 고정한 rhwp 웹 Studio와 vendored WASM을 이용한다. HOP 데스크톱 UI를 웹에 그대로 옮긴 구조는 아니다. 상단의 검증용 제목·안내문·버튼 열을 제거하고, 파일 메뉴에 새 문서·열기·저장·다른 이름 저장·저장 형식·문서 형식 선택을 배치했다. 상태 메시지는 작은 하단 영역에 표시한다.

분리 전 EdenText 커밋과 미커밋 변경, 의존성을 포함한 원본 작업 폴더는 `backups/edentext-custom-worktree`에 보존했다. bundle과 patch도 별도로 보존했으며 루트 Git에 포함하지 않는다.

## 채택한 버전

| 구성 | 커밋 |
|---|---|
| EdenText 0.9.0 | `4c4c94cb46b9c0b1473b9dd323315f9c4d365251` |
| HOP 0.4.5 | `80888af2b8c8a18aea16f824d2d92309a290b1ad` |
| rhwp 0.8.7 | `1a76570e833917d15817415a53c09ad61ab3203f` |

EdenText 후보 업데이트에서 삭제된 AI 번역 키가 타입 검사를 실패시켰다. 한국어 사전을 독립 overlay로 분리하고 현재 번역 타입에 맞췄다. 실패했던 후보는 기존 체크아웃으로 복귀했고 lock을 변경하지 않았다. 이후 후보 검증을 통과한 커밋을 채택했다. 미래 업데이트에도 패치 조정이 필요할 수 있다.

## 실행 결과

- `npm run upstream:check -- --edentext origin/main`: 후보 빌드·타입 검사·단위 검사·Chrome 회귀 검사 통과. 원래 체크아웃으로 복귀 확인.
- 검증 뒤 임시 제품 파일을 추가한 상태에서 promote: 거부 확인. lock과 원본 HEAD 불변 확인. 임시 파일 제거 후 검증된 후보를 채택.
- `npm run verify`: 루트·Word 타입 검사, 저장 계약 검사 3건, 프로덕션 Chrome 통합 검사 통과. 보고서 `artifacts/verified.json`, 산출물 `dist/`.
- `node tests/integration.mjs --dev`: localhost 개발 서버에서도 동일한 저장·재열기 회귀 검사 통과.
- 브라우저 검사: 한국어 메뉴, DOCX 기본 저장, 본문·표 포함 DOCX, Word→HWPX/HWP 저장과 네이티브 재열기, 굵은 글씨·표 행 높이·열 너비 보존, 네이티브 본문·표 왕복, 실패한 열기 이후 기존 문서 유지, 오래된 저장 응답 처리, 외부 수정 감지, 원본 보호, 사본 저장 후 대상 변경 확인.
- 프로덕션 Word 오프라인 재로딩 확인. 서비스 워커 소유권은 루트 셸로 이동했다. 한글 엔진 오프라인 사용은 보장하지 않는다.
- 파일 메뉴 펼침·접힘 화면 확인. 기존 검증용 헤더와 안내문이 표시되지 않는다.
- 검증 후 두 원본 클론의 작업 트리 변경 없음 확인.

검증한 제품 해시: `da2c8f3ba0cb543ce4061d1a299e1903fe274c6e5406d711ee0970927bb76487`.

## 남은 수동 확인과 범위

자동 저장 검사는 Chrome OPFS 핸들로 OS 선택기를 대신한다. 실제 디스크 파일 선택기, 한컴/Word에서 출력물 재열기, 한국어 IME 입력은 사용자 배포 전 별도 확인해야 한다. 가져온 한글 원본 덮어쓰기·한글 자동 복구는 아직 미지원이다. 검증한 본문·표 이외의 모든 고급 문서 요소 보존을 보장하지 않는다.

라이브 배포와 원격 push는 수행하지 않았다. 이전 `source/edentext` 서버는 사용자가 종료한 후 프로젝트 루트에서 다시 실행해야 한다.
