## 단계

| 단계 | 할 일 | 완료 조건 | 검증 |
|---|---|---|---|
| 1. upstream 관리 확장 | lock에 `gridcraft`·`craftLibs` 추가. `upstream-git`·`upstreams`(sync·candidate·promote·복귀)·`verifySources`·`mirrors`·`release-info`를 이름 목록으로 일반화. craft-libs 커밋은 gridcraft `Cargo.lock`에서 읽어 맞춘다 | 기존 edentext·hop·rhwp 보호 동작 그대로. 새 항목도 더러운 클론이면 중단, 실패 시 원래 HEAD 복귀. lock의 craft-libs 커밋 ≠ `Cargo.lock`이면 빌드 실패 | `npm run test:contracts`(새 시험 포함), `npm run upstream:sync` |
| 4a. gridcraft 재현 빌드 | `.cache/build/gridcraft` 복사본(소유 표식)에 overlay 적용(`git apply --check`) → trunk → `public/engines/gridcraft/`. 도구 판 검사, 입력 해시가 같으면 재빌드 생략, cargo target은 일반·후보 분리. 해시 파일을 `assets/`로 옮겨 HTML 참조를 정확 치환 | 원본 클론 무변경. 도구 판이 다르면 실패. WASM < 25MiB. 한국어 글꼴 포함. provenance에 도구·Cargo.lock·overlay·글꼴 해시 | `npm run prepare:engines`, `npm run test:contracts` |
| 4b. 고지·manifest | wasm32 대상 Cargo 의존 집합(`cargo metadata --filter-platform`)의 라이선스·NOTICE 수집, Pretendard OFL, gridcraft·craft-libs 고지. ArtCraft 표지(정보 창 "Part of ArtCraft"·Discord) 제거·대체. Trunk 산출물 전용 manifest 수집기(`xlsx` 항목, 미리 받기 목록에는 넣지 않음 = 고를 때 받기). `_headers`(assets만 immutable)·`sw.js`(gridcraft 캐시 제외) | 라이선스 파일 없는 crate는 명시 목록과 정확히 일치해야 통과. 참조 파일 누락 시 실패 | `npm run test:contracts`, `npm run build` |
| 4c. 보기 브리지·읽기 전용 | overlay로 `?host=sketch` 브리지: 프로토콜 판·요청 ID·epoch, origin·source 검사, 열기 결과(성공·시트 수·경고·실패). 읽기 전용 2중 차단: ① 엔진 `Session::execute` 허용 목록(query·탐색·복사만) ② 매 프레임 workbook이 열 때와 다르면 되돌리고 보고. 저장·내보내기·인쇄·파일 선택·끌어놓기 차단. 단독 방문은 제품 셸로 보냄 | 키 입력·붙여넣기·직접 명령·메뉴 저장으로 workbook·파일이 바뀌지 않음. 실패한 열기는 이전 문서 유지. 늦은 결과 무시 | 제안 `TEST_DIST=dist node tests/xlsx.integration.mjs`(자체 생성 fixture) |
| 4d. Excel 제품 진입 | `xlsx.html`·`src/xlsx.ts`·routes·EditorShell·EditorControls·첫 화면 카드·vite 입력. 헤더는 iframe 밖, "보기 전용" 표시 | 카드·버튼·직접 URL·뒤로/앞으로·새로고침이 같은 엔진. 한국어 셀 표시. Word·한글·PDF 상태 유지. 외부 요청 0 | `npm run verify` |

각 단계는 검증 뒤 독립 커밋한다. 무거운 실행(verify·브라우저 회귀 전체·trunk/cargo·Codex 리뷰)은 조율자 허락 뒤에 한다.

## 알려진 영향

- 4a 이후 `npm run verify`는 Rust 1.99.0·trunk·wasm-bindgen·wasm-opt가 있는 기기에서만 통과한다. GitHub Actions `verify`는 단계 5에서 도구를 등록하기 전까지 실패한다(push하지 않으므로 지금은 영향 없음).
- 보존 mirror(GitHub `HWJskt/gridcraft`·`HWJskt/craft-libs`)는 만들지 않는다 — 공개 행위라 사용자 결정. 그 전에는 `mirrors:check`가 실패해 배포가 막힌다(의도한 동작).
- UI 메뉴는 영어다(gridcraft `i18n`에 한국어 없음).
