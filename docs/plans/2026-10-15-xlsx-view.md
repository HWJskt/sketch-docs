## 알려진 영향

- 4a 이후 `npm run verify`는 Rust 1.99.0·trunk·wasm-bindgen·wasm-opt가 있는 기기에서만 통과한다. GitHub Actions `verify`는 단계 5에서 도구를 등록하기 전까지 실패한다(push하지 않으므로 지금은 영향 없음).
- 보존 mirror(GitHub `HWJskt/gridcraft`·`HWJskt/craft-libs`)는 만들지 않는다 — 공개 행위라 사용자 결정. 그 전에는 `mirrors:check`가 실패해 배포가 막힌다(의도한 동작).
- UI 메뉴는 영어다(gridcraft `i18n`에 한국어 없음).

### 결정·발견

- 읽기 전용은 엔진 명령 허용 목록(질의·선택·이동·찾기·복사, workbook을 바꾸는 질의 `formulas.watchWindow` 제외)과 매 프레임 되돌림 두 층이다. 열기는 브리지가 `file.open` 한 번만 허가한다(게이트 전체를 끄지 않는다. 텍스트 상자 초안은 먼저 버린다). 그리드 필터 단추처럼 명령을 거치지 않는 UI 직접 변경은 가드 한 층만 막는다.
- gridcraft는 ZIP이 아닌 바이트를 텍스트로 연다. 셸은 `.xlsx` 확장자와 ZIP 서명을 먼저 검사한다. 100MB 상한은 셸·엔진 둘 다.
- 최신 요청 하나만 결과로 인정한다. 시간 초과(60초) 뒤 같은 요청의 늦은 답은 한 번만 반영한다.
- 서비스 워커는 Excel 엔진을 캐시하지 않는다(오프라인 Excel 보기 없음). 엔진은 고를 때만 받는다.
- 단독 방문(`engines/gridcraft/index.html`)은 `/xlsx`로 보낸다. `?host=sketch` 없이 프레임에 넣으면 시작하지 않는다.

### 한계·남은 일

- 엔진 UI(메뉴·저장 아이콘·AutoSave 등)는 영어이고 편집 메뉴가 그대로 보인다. 누르면 거절되고 엔진이 영어 경고 창을 띄운다(셸에는 한국어 안내).
- 확인하지 못한 것: Safari·Firefox, WebGL2 강제(`?webgl`) 경로, 큰 통합 문서의 시간·메모리, 시작 시간, 차트·병합·조건부 서식 등 형식별 표시, 굵은 한국어 글꼴(Regular만 넣음), 실제 OS 파일 선택기, 프레임 가드 단독 경로를 실제 UI 직접 변경(예: 필터 단추)으로 일으킨 시험.
- GitHub Actions `verify`는 Rust 1.99.0·trunk·wasm-bindgen·wasm-opt가 없어 실패한다 — §9 단계 5에서 등록한다. push 전에 해야 한다.
- 보존 fork(`HWJskt/gridcraft`·`HWJskt/craft-libs`) 생성과 `mirrors:pin`은 배포 직전 사용자 승인으로 한다(2026-10-15 결정 A). 그 전에는 배포가 거절된다.
