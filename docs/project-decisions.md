# 직원용 문서 편집기 결정 기록

기준일: 2026-10-11

병원 직원이 웹에서 Word와 한글 문서를 작성·편집하고 로컬 디스크에 저장하는 프로그램을 개발한다. 제품 코드는 프로젝트 루트에서 관리하고, EdenText와 HOP는 고정된 원본 클론으로 사용한다. 이 기록은 현재 채택한 구조와 운영 방향을 정리하며, 구현 완료와 배포 전 남은 작업을 구분한다.

## 사용 목적과 편집 화면

- 우선 대상은 병원 내부 직원이며 웹앱을 첫 사용 환경으로 삼는다.
- 첫 화면에서 Word 또는 한글 편집기를 선택한다. Word 문서는 EdenText, 한글 문서는 HOP가 고정한 rhwp 웹 Studio와 vendored WASM으로 편집한다. HOP 데스크톱 프로그램 전체를 웹에서 실행하는 구조는 아니다.
- 로컬 문서 열기·편집·저장·다른 이름으로 저장, 새 문서의 DOCX/HWPX 저장이 핵심 목표다. 전체 목표는 [개발 목표](project-goals.md)를 따른다.
- EdenText의 기본 언어는 한국어로 유지한다. Word의 다른 이름으로 저장에는 DOCX/ODT를 유지하고 HWPX/HWP 항목은 노출하지 않는다.
- 한글 파일 메뉴는 편집 메뉴 바로 왼쪽에 둔다. 편집 메뉴와 같은 세로 드롭다운을 사용한다.
- 한글 파일 메뉴에는 새 문서, 열기, 저장, 다른 이름으로 저장 (.hwpx), 다른 이름으로 저장 (.hwp), 문서 형식 선택을 배치한다. 별도의 저장 형식 select는 사용하지 않는다.
- 기존 Word→한글 변환 코드는 보존되어 있으나 현재 저장 메뉴로 제공하지 않는다. 초기 목표 문서의 형식 간 변환은 현재 제공 기능과 구분한다.

## 저장소 소유와 폴더 구성

프로젝트 위치는 `/Users/hwjung/Coding/edentext-word-hwp`다. 루트 Git 저장소는 이미 초기화되어 있다.

| 대상 | 관리 방식 |
|---|---|
| `src/`, HTML 진입 화면 | 우리 화면과 편집기 연결 코드, Git 추적 |
| `overlays/` | 한국어 번역·원본에 적용할 패치·한글 메뉴 및 브리지, Git 추적 |
| `scripts/`, `tests/`, `docs/` | 빌드·업데이트·검증·문서, Git 추적 |
| `upstreams.lock.json`, 패키지 lock | 재현에 필요한 정확한 버전 정보, Git 추적 |
| `source/edentext`, `source/hop` | 별도 원본 Git 클론, 루트 `.gitignore`로 제외 |
| `source/hop/third_party/rhwp` | HOP의 고정 서브모듈 |
| `backups/` | 이전 수정 저장소와 사용자 작업 보존, Git 제외·삭제 금지 |
| 의존성·캐시·생성된 엔진·빌드 결과 | Git 제외, 빌드로 생성 |

원본 클론을 직접 수정하지 않는다. 빌드용 복사본에 우리 패치를 적용한다. 모든 upstream 코드를 루트 저장소에 합쳐 커밋하는 방식은 채택하지 않는다.

현재 GitHub 원격은 연결되지 않았다. 저장소 이름과 Public/Private 설정은 별도 결정 대상이다. 로컬 커밋은 원격 push나 라이브 배포를 뜻하지 않는다.

## 원본 버전과 업데이트

버전의 기준은 `upstreams.lock.json`에 기록된 저장소 URL과 전체 커밋 SHA다. 아래 표는 기록 시점의 스냅샷이며, 이후에는 lock 파일을 우선한다.

| 프로젝트 | 버전 | 고정 커밋 |
|---|---|---|
| EdenText | 0.9.0 | `4c4c94cb46b9c0b1473b9dd323315f9c4d365251` |
| HOP | 0.4.5 | `80888af2b8c8a18aea16f824d2d92309a290b1ad` |
| rhwp | 0.8.7 | `1a76570e833917d15817415a53c09ad61ab3203f` |

새 환경에서는 `npm ci`와 `npm run upstream:sync`로 의존성과 고정된 원본을 준비한다. 매번 upstream의 최신 main을 자동 채택하지 않는다.

업데이트 순서는 원격 fetch → `upstream:check`로 후보 검증 → `upstream:promote`로 채택 → `npm run verify`로 최종 검증 → 변경된 lock과 필요한 패치를 커밋하는 것이다. 명령 전문은 [README](../README.md#업데이트-후보-검증)를 따른다.

후보 검사는 별도 빌드 폴더에서 수행하고 종료 후 원래 체크아웃으로 복귀한다. 패치 적용·타입 검사·회귀 검사에 실패하면 채택하지 않는다. 검증 뒤 우리 코드가 변경되면 다시 후보 검증을 해야 한다. 향후 모든 upstream 변경이 수정 없이 호환된다고 보장하지 않는다.

## 소스 제공과 라이선스 운영 방향

개발 저장소에는 우리 코드와 버전 정보를 관리하고, 배포 버전마다 우리 코드·고정된 원본·필요한 빌드 자료·라이선스를 포함한 대응 소스 압축파일을 별도로 보관·제공하는 방향을 채택한다. 이 릴리스 소스 패키징과 다운로드 안내는 아직 구현하지 않았다.

EdenText는 AGPL-3.0-only, HOP와 rhwp의 최상위 코드는 MIT다. GitHub 저장소를 Public으로 만드는 것은 필수가 아니지만, 배포판의 대응 소스를 실제 이용자에게 제공할 수 있어야 한다. 우리 수정본을 포함해야 하며 upstream 링크만으로 대체하지 않는다. 소스를 받은 이용자의 라이선스상 재배포 권리를 제한하는 방식으로 비공개를 보장할 수는 없다. [AGPL 원문](https://opensource.org/license/agpl-3.0)

라이선스는 앱 로그인을 요구하지 않는다. 직원 전용 SSO·VPN 등 접근 통제는 권장 방향이며, 인증 방식과 제공 업체는 미정이다. 병원 문서·환자정보·운영 비밀값은 소스 패키지에 포함하지 않는다. 의존성·폰트 고지와 세부 검토는 [라이선스 기록](validation/2026-10-11-licenses.md)을 따른다.

## 도메인 구성

| 주소 | 용도 | 상태 |
|---|---|---|
| `sketchps.com` | 병원 대외 홈페이지 | 사용자가 기존 병원 도메인으로 확인 |
| `sketchps.app` | 직원 포털과 업무 프로그램의 기본 도메인 | 사용자가 구매 완료를 확인 |
| `doc.sketchps.app` | 이 프로젝트의 문서 편집기 | `text`와 비교 후 추천한 배포 주소안 |
| `erp.sketchps.app` | ERP | 계획 주소 |

추가 도메인 후보 중 직원용 앱이라는 용도와 기존 병원 이름의 일관성을 고려해 `sketchps.app`을 선택했다. `sketchplastics.app`, `.org`, `.dev`는 현재 운영 주소로 채택하지 않았다. 문서 편집기 주소는 Word·한글 문서를 다루는 용도를 드러내는 `doc`을 추천했다.

직원은 기본 도메인의 포털에서 프로그램으로 이동하는 구성을 권장한다. 포털 구현, DNS, 호스팅, HTTPS 인증서, 로그인 연결은 아직 실행하지 않았다. 도메인 구매는 배포 완료를 뜻하지 않는다.

## 검증과 배포 전 남은 작업

라이브 배포에 앞서 localhost에서 확인한다. `npm run verify`와 개발 서버 회귀 검사에서 메뉴·DOCX 저장·한글 HWP/HWPX 저장 및 재열기 등을 확인했다. 최근 결과는 [파일 메뉴 검증](validation/2026-10-11-file-menus.md)에 기록되어 있다.

다음은 완료로 취급하지 않는다.

1. 실제 OS 파일 선택기, Word·한컴오피스에서 재열기, 한국어 IME와 대표 병원 문서 검증.
2. 가져온 한글 원본 덮어쓰기와 한글 자동 복구 등 최종 목표에 남은 기능.
3. 의존성·폰트 고지 보완. 릴리스 소스 압축파일 자동 생성과 이용자 다운로드 안내는 2026-10-12 구현했다.
4. GitHub 원격 및 공개 범위, 호스팅·직원 인증 방식 확정.
5. `doc.sketchps.app` DNS·HTTPS 연결과 실제 배포. 사용자 요청 전 자동 배포·push는 하지 않는다.

실행 절차는 [README](../README.md), 전체 목표는 [개발 목표](project-goals.md), 이전 계획과 검증 결과는 기존 문서에 보존한다. 이후 결정이 바뀌면 이 기록의 해당 항목과 연결 문서를 함께 갱신한다.

## Sketch Docs 제품 정보와 공통 화면

사용자가 제품명을 **Sketch Docs**로 확정했다. 저작권자 명칭은 미지정이며 임의의 병원 법인명을 넣지 않았다. 첫 화면과 두 편집기의 공통 헤더에서 프로그램 정보, AGPL 원문, 구성요소 고지, 현재 빌드의 대응 소스 링크(GitHub)를 제공한다. 편집기 전환은 두 문서를 각각 유지하며 파일 형식을 변환하지 않는다. 구현과 남은 검증은 [공통 셸 검증](validation/2026-10-12-common-shell.md)에 기록한다.

## 공개 저장소와 소스 제공 (2026-10-12)

- 서비스 주소는 `docs.sketchps.app`, 공개 저장소는 `HWJskt/sketch-docs`이다. 기존 Git 이력을 그대로 공개한다.
- 공개 저장소에는 우리 코드만 둔다. EdenText·HOP·rhwp는 `upstreams.lock.json`의 고정 커밋으로 복원하며, 원본이 사라질 때를 대비해 HWJskt 계정의 fork에 `sketch-docs/pin-<commit>` 태그로 고정 커밋을 보존한다.
- 배포판에는 소스 압축을 넣지 않고, 정보 창에서 빌드 커밋의 GitHub 링크와 원본·보존 fork의 고정 커밋 링크를 제공한다.
- 배포는 로컬 `npm run verify` 결과만 `npm run deploy`로 Cloudflare Pages에 직접 올린다. 명시 요청 때만 배포한다. 세부 절차는 [공개 배포 계획](plans/2026-10-12-public-release.md).
