## 방법

- **경로가 제품과 같다.** 빌드된 엔진(gridcraft `d9d09f0` + overlays, `00d2fd9`)에 브리지로 열고, 스냅샷(`sketch-xlsx:snapshot` — 저장이 쓰는 것과 같은 바이트)을 받는다. CLI는 쓰지 않았다(리뷰 11: 경로가 다르다).
- 비교는 `src/xlsx/compare.ts`(관계 그래프·해석된 서식·그림 바이트 기준)로 한다.
- **같은 뜻의 다른 표기는 차이로 세지 않는다.** 아래 "정규화" 목록이 그 규칙이고, 단위 시험이 그 규칙을 고정한다.
- 엔진이 쓴 파일을 한 번 더 왕복해 그 결과가 같은지(안정성)도 쟀다.

fixture 13개 — `tests/fixtures/xlsx-roundtrip/`, 실제 업무 문서 없음:
- 생성기: `scripts/xlsx-roundtrip/fixtures.py`(openpyxl 3.1.5, Python 3.9.6), `extras.mjs`(그림·custom XML·사용자 속성·xlsx 안 VBA)
- 담은 기능 묶음: 값·날짜·1904 날짜계, 수식(배열 수식·이름·다른 시트 참조), 서식(글꼴·채우기·테두리·맞춤·보호·서식 있는 텍스트), 배치(병합·열 너비·행 높이·숨김·그룹·틀 고정·확대·눈금선·탭 색·숨김/매우 숨김 시트·오른쪽부터), 조건부 서식 5종·데이터 유효성 3종, 메모·하이퍼링크 3종, 표·자동 필터, 차트 3종, 인쇄 설정·시트/통합 문서 보호, 그림, custom XML·사용자 속성, VBA

### 정규화 — 같은 뜻으로 보고 차이로 세지 않은 것

- 불리언 표기(`1`/`true`), 스키마 기본값의 생략·명시. 대상: 데이터 유효성·표 스타일·자동 필터·페이지 설정·인쇄 옵션·개요·시트 보호의 기본값, `orientation` portrait = default.
- 시트 이름 따옴표(`'매출'!A1` = `매출!A1`, 따옴표가 필요 없는 이름만).
- 지수 표기(`1.157e-05` = `1.157E-5`).
- 원본에 캐시가 없던 수식의 계산 값, 배열 수식이 채운 칸.
- 색 `indexed 64`·`auto`(시스템 자동색 = 지정 없음). 조건부 서식 단색 채우기에서 bgColor와 같은 fgColor.
- 셀 서식 글꼴에 없는 이름·크기·색은 기본 글꼴(0번)에서 가져온다.
- Excel 내부용 숨긴 이름 `_xlnm._FilterDatabase`, 행 그룹에서 파생되는 `outlineLevelRow/Col`.
- 여백은 1/10000인치까지만 비교한다.

## 한계 — 이 측정이 말하지 않는 것

- **Excel이 직접 쓴 파일이 아니다.** openpyxl은 Excel보다 단순하게 쓴다.
- 이 fixture에 없는 것: 피벗 테이블, 스레드 댓글, 스파크라인·슬라이서(`extLst`), 외부 통합 문서 연결, 데이터 연결, 컨트롤·OLE, 테마 변경, 셀 스타일 이름, 차트 서식 세부.
- 위 둘은 **실제 문서(결정 Q9)** 로 다시 재야 한다.
- 비교기가 보지 않는 항목은 "유지"로 보이지만 확인한 것이 아니다. 예: 테마 part 내용, `app.xml`, 계산 설정 `calcPr`, 셀 스타일(`cellStyles`) 이름, 시트 보기의 선택 영역. 비교 항목은 `src/xlsx/compare.ts` 머리말과 코드가 정본이다.

## 저장 판정에 주는 뜻 (단계 2a 입력)

- 원본 저장을 막을 손실(판정 1) 후보:
  - 서식 있는 텍스트가 있는 파일
  - 시트 보호가 있는 파일(옵션이 바뀐다)
  - VBA가 든 `.xlsx`
  - 측정하지 못한 요소(피벗·스레드 댓글·`extLst` 등)가 든 파일 — 비교기가 읽지 않는 part 종류(`part-kind`)나 `extensions`가 원본에 있으면 손실로 본다
- `created` 손실은 모든 파일에서 난다. 이것까지 막으면 원본 저장이 불가능해진다. → **결정 질문 Q13**(결정 파일): `created`를 허용 차이로 둘지, 엔진을 고쳐(overlay) 보존할지.
